## How to use it

1. Download MAC_ORGANIZER_HANDOFF.md.
2. Open Terminal: press Command-Space, type Terminal, and press Return.
3. Install Claude Code. Paste this line and press Return: `curl -fsSL https://claude.ai/install.sh | bash`
4. Make an empty folder for the work: `mkdir ~/organise`
5. Move the file into it. Your browser saves to Downloads unless you changed that: `mv ~/Downloads/MAC_ORGANIZER_HANDOFF.md ~/organise/`
6. Go into the folder: `cd ~/organise`
7. Start Claude Code, and sign in when it asks: `claude`
8. Say: "Read MAC_ORGANIZER_HANDOFF.md and follow it. Start with step 0."

Expect it to take days, not minutes. Claude proposes and you approve. Nothing is permanently deleted unless you do it yourself.
